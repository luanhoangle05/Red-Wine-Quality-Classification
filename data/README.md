# Dataset attribution

This directory contains `winequality-red.csv`, the red-wine portion of the
Wine Quality dataset created by Paulo Cortez, António Cerdeira, Fernando
Almeida, Telmo Matos, and José Reis.

- Original repository: UCI Machine Learning Repository
- Dataset page: <https://archive.ics.uci.edu/dataset/186/wine+quality>
- DOI: <https://doi.org/10.24432/C56S3T>
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Local file: 1,599 red-wine observations, 11 physicochemical input variables,
  and one sensory quality score

## Requested citation

Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). *Wine
Quality* [Dataset]. UCI Machine Learning Repository.
<https://doi.org/10.24432/C56S3T>

The dataset was also distributed through Kaggle at:
<https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009>.
